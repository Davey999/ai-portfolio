# Website Builder Methodology

## Business Context

Building a website from a visual reference is a repeatable process — yet most AI-assisted builds treat it as a one-off creative task. Each build starts from scratch, quality is inconsistent, and important steps like QA and design systems are skipped.

## What It Does

An 8-phase workflow with defined outputs and exit criteria at each stage:

1. Reference
2. Discovery
3. Pre-flight
4. Build
5. Design system
6. QA
7. Content
8. Ship

Encoded as a reusable Claude Code skill so any future build starts from a proven foundation rather than a blank canvas.

## Proof of Concept

This portfolio site (davidmerry.me) was built end-to-end using the methodology, including:

- Full CSS design system
- WCAG AA contrast compliance across both dark and light modes
- Mobile-responsive navigation
- Multi-page routing
